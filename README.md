Clash of Clans Auto Clicker
یک اتو کلیکر ساده با Python برای تکرار خودکار یک چرخه از کلیک‌ها و فشردن
کلیدهای کیبورد در نسخه دسکتاپ Clash of Clans. این پروژه برای Windows
11 و توسعه در VS Code آماده شده است.
توجه: این ابزار بر اساس مختصات ثابت صفحه کار می‌کند. تغییر رزولوشن،
اندازه پنجره، محل بازی یا رابط کاربری ممکن است باعث شود روی نقاط
اشتباه کلیک کند. ابتدا آن را در شرایط امن آزمایش کنید و قوانین بازی
درباره اتوماسیون را در نظر بگیرید.

قابلیت‌ها
- اجرای خودکار یک چرخه شامل کلیک روی هفت نقطه از صفحه
- اجرای مرحله فارم شامل ۳۰ کلیک و فشردن کلیدهای 1، Z، A و توالی
  QWER
- تکرار پیوسته چرخه‌ها
- شروع با F6
- توقف با F7
- امکان توقف اضطراری با بردن ماوس به گوشه بالا-چپ صفحه (قابلیت
  Fail-safe کتابخانه PyAutoGUI، برای عملیات انجام‌شده با خود PyAutoGUI)
- ابزار جداگانه برای پیدا کردن مختصات نقاط صفحه
فایل‌های پروژه
  فایل                                کاربرد
  auto_clicker.py                   اسکریپت اصلی اتو کلیکر؛ چرخه را
                                      اجرا می‌کند و کلیک‌ها و کلیدها را
                                      مدیریت می‌کند.

  get_positions.py                  ابزار ثبت مختصات ماوس؛ با فشردن
                                  F2 مختصات فعلی ماوس را چاپ می‌کند.
پیش‌نیازها
- Windows 11
- Python نصب‌شده
- Visual Studio Code (اختیاری، برای ویرایش و اجرا)
- نصب کتابخانه‌های Python زیر:

نصب
۱. دریافت پروژه
فایل‌های auto_clicker.py و get_positions.py را در یک پوشه قرار دهید و
آن پوشه را در VS Code باز کنید. اگر پروژه را از GitHub دریافت کرده‌اید،
می‌توانید آن را با Git کلون کنید.
۲. ساخت محیط مجازی (پیشنهادی)
در ترمینال VS Code و داخل پوشه پروژه اجرا کنید:
python -m venv .venv
فعال‌سازی محیط مجازی در PowerShell:
.\.venv\Scripts\Activate.ps1
اگر PowerShell اجازه فعال‌سازی نداد، می‌توانید از ترمینال Command Prompt
استفاده کنید یا دستور نصب را با مسیر مستقیم Python محیط مجازی اجرا کنید.
۳. نصب وابستگی‌ها
python -m pip install pyautogui keyboard pynput
راهنمای استفاده
مرحله اول: پیدا کردن مختصات
ابتدا ابزار مختصات را اجرا کنید:
python get_positions.py
1. ماوس را دقیقاً روی نقطه‌ای از بازی ببرید که اتو کلیکر باید روی آن کلیک
   کند.
2. کلید F2 را فشار دهید.
3. مختصات X و Y در ترمینال چاپ می‌شود؛ برای مثال:
   نقطه 1: (48, 524)
4. این کار را برای تمام نقاط موردنیاز تکرار کنید.
5. برای بستن ابزار، Esc را فشار دهید.
نکته: این ابزار مختصات را فقط چاپ می‌کند و آن‌ها را به‌صورت خودکار داخل
auto_clicker.py ذخیره نمی‌کند. باید مقادیر را دستی در بخش تنظیمات کپی
کنید. شماره نقاطی که ابزار چاپ می‌کند بر اساس ترتیب فشردن F2 افزایش
می‌یابد؛ آن‌ها را با دقت به متغیرهای درست نسبت دهید.
مختصات در اسکریپت اصلی
در ابتدای auto_clicker.py این متغیرها تعریف شده‌اند:
POINT_1 = (48, 524)
POINT_2 = (129, 414)
POINT_3 = (777, 492)
POINT_4 = (112, 287)
POINT_5 = (53, 457)
POINT_6 = (555, 363)
POINT_7 = (474, 493)
اعداد بالا مختصات فعلی موجود در فایل‌اند و صرفاً نمونه‌ای برای تنظیم اولیه
این نسخه محسوب می‌شوند. مختصات خودتان را جایگزین کنید. POINT_4 نقطه‌ای
است که در مرحله فارم برای کلیک‌های متعدد و کلیک‌های همراه کلیدها استفاده
می‌شود.

مختصات به پیکسل و نسبت به صفحه دسکتاپ هستند؛ بنابراین اندازه پنجره و
رزولوشن نمایشگر را در طول استفاده ثابت نگه دارید.
مرحله دوم: اجرای اتو کلیکر
python auto_clicker.py
- پس از نمایش پیام آماده‌بودن، F6 را فشار دهید تا چرخه شروع شود.
- برای توقف، F7 را فشار دهید.
- همچنین می‌توانید Ctrl+C را در ترمینال بزنید.
- برای عملیات مبتنی بر PyAutoGUI، بردن ماوس به گوشه بالا-چپ صفحه نیز
  می‌تواند Fail-safe را فعال کند. با این حال، برای توقف قابل‌اتکاتر از
  F7 استفاده کنید.
پیش از شروع، مطمئن شوید پنجره بازی در وضعیت درست قرار دارد و مختصات
آزمایش شده‌اند. بهتر است اولین اجرا را زیر نظر داشته باشید.
ترتیب اجرای چرخه
اسکریپت اصلی به‌صورت پیوسته مراحل زیر را اجرا می‌کند:

  مرحله   عملیات                                                      مکث پس از عملیات
  ۱       کلیک روی POINT_1                                                   ۱ ثانیه
  ۲       کلیک روی POINT_2                                                   ۱ ثانیه
  ۳       کلیک روی POINT_3                                                   ۵ ثانیه
  ۴       اجرای توالی فارم روی POINT_4                                      ۷۰ ثانیه
  ۵       کلیک روی POINT_5                                                   ۱ ثانیه
  ۶       کلیک روی POINT_6                                                   ۲ ثانیه
  ۷       کلیک روی POINT_7                 ۶ ثانیه پس از کلیک، پیش از شروع چرخه بعدی

پس از مرحله آخر، شماره چرخه افزایش پیدا می‌کند و مراحل دوباره از ابتدا
اجرا می‌شوند.
جزئیات مرحله فارم
تابع farm_sequence() مرحله فارم را اجرا می‌کند. ترتیب فعلی کد چنین است:
1. کلید 1 را فشار می‌دهد و ۰٫۱ ثانیه صبر می‌کند.
2. روی POINT_4 تعداد ۱۵ بار کلیک می‌کند؛ فاصله بین کلیک‌ها ۰٫۰۳ ثانیه
   است.
3. کلید Z را فشار می‌دهد، ۰٫۱ ثانیه صبر می‌کند و یک بار روی POINT_4
   کلیک می‌کند.
4. پنج بار این کار را انجام می‌دهد: فشردن A، مکث ۰٫۱ ثانیه، کلیک روی
   POINT_4 و مکث ۰٫۱ ثانیه.
5. تعداد ۱۵ کلیک دیگر روی POINT_4 انجام می‌دهد؛ در نتیجه مجموع کلیک‌های
   بخش ۱۵+۱۵ برابر ۳۰ می‌شود.
6. دو بار توالی QWER را اجرا می‌کند. برای هر یک از کلیدهای Q، W،
   E و R، ابتدا کلید فشرده می‌شود، ۰٫۱ ثانیه مکث می‌کند، یک بار روی
   POINT_4 کلیک می‌کند و دوباره ۰٫۱ ثانیه مکث می‌کند.
توضیح شمارش کلیک‌ها: مقدار TOTAL_CLICKS = 30 به دو بخش ۱۵ کلیکی
تقسیم شده است. کلیک‌های همراه Z، پنج کلیک همراه A و کلیک‌های همراه
QWER جدا از آن ۳۰ کلیک انجام می‌شوند؛ بنابراین تعداد کل کلیک‌های واقعی
مرحله فارم بیشتر از ۳۰ است.
تنظیم سرعت و رفتار
این مقادیر در ابتدای auto_clicker.py قرار دارند:
TOTAL_CLICKS = 30
CLICK_DELAY = 0.03
CLICKS_AFTER_1 = 15
- TOTAL_CLICKS: تعداد کلیک‌های بخش اصلی فارم؛ مقدار فعلی ۳۰ است.
- CLICK_DELAY: فاصله زمانی بین کلیک‌های بخش اصلی؛ مقدار 0.03 یعنی
  ۳۰ میلی‌ثانیه.
- CLICKS_AFTER_1: تعداد کلیک‌های بخش اول پس از فشردن 1. تعداد
  کلیک‌های بخش دوم از تفاضل TOTAL_CLICKS - CLICKS_AFTER_1 محاسبه
  می‌شود.
زمان‌های مکث مراحل اصلی و مرحله فارم مستقیماً در کد با time.sleep(...)
مشخص شده‌اند. برای تغییر آن‌ها، مقدار مناسب را در همان بخش ویرایش کنید.
نکات فنی
- PyAutoGUI برای کلیک روی نقاط مراحل اصلی و قابلیت Fail-safe استفاده
  شده است.
- pynput برای جابه‌جایی ماوس و کلیک سریع در تابع fast_click() به
  کار رفته است.
- کتابخانه keyboard برای تشخیص کلیدهای شروع/توقف و ارسال کلیدهای
  بازی استفاده می‌شود.
- پیام‌های ترمینال، شماره چرخه و مراحل اجرا را نشان می‌دهند.
- اسکریپت به تشخیص تصویر یا پیدا کردن خودکار عناصر بازی مجهز نیست؛
  تمام عملیات بر اساس مختصات ثابت انجام می‌شوند.
- در کد فعلی، توقف با F7 از طریق یک رشته جداگانه بررسی می‌شود و
  برنامه را فوراً خاتمه می‌دهد.
عیب‌یابی
کلیک‌ها در جای اشتباه انجام می‌شوند
- get_positions.py را اجرا کنید و مختصات را دوباره بگیرید.
- مطمئن شوید رزولوشن نمایشگر و اندازه پنجره بازی تغییر نکرده است.
- بررسی کنید مقادیر POINT_1 تا POINT_7 را درست وارد کرده باشید.
کلیدها در بازی عمل نمی‌کنند
- مطمئن شوید پنجره بازی فعال است و ورودی کیبورد را دریافت می‌کند.
- بررسی کنید زبان و وضعیت کیبورد با کلیدهای مورد انتظار بازی سازگار
  باشد.
- ابتدا عملکرد را با اجرای کوتاه و تحت نظارت آزمایش کنید.
